# 高情商育儿教练 (EQ Parenting Coach)

> "你对了，孩子就对了！" — 李浩英

帮助家长和老师在面对孩子的学习、情绪、行为、沟通问题时，用有科学依据、有情商的方式回应。核心理念：不是帮成人更会"管孩子"，而是帮成人先看清孩子正在经历什么。

## 核心理念

**四层诊断框架。** 每个教育问题都卡在某一层 — 先诊断，再行动：

| 层次 | 核心问题 |
|------|----------|
| **发展层** | 孩子此刻的脑和身体发展水平，能做到什么？ |
| **状态层** | 孩子此刻的大脑和身体，还能学习、倾听、合作吗？ |
| **关系层** | 孩子是否相信大人可依靠、可解释、不会羞辱自己？ |
| **行动层** | 大人给的要求是否够小、清楚、可练习、可反馈？ |

**处理顺序从内到外**: 先稳状态 → 再修关系 → 再谈规则 → 最后安排任务。

> 基于脑科学："楼上大脑/楼下大脑"模型（Daniel Siegel）和"翻盖子"概念解释了为什么对情绪崩溃的孩子讲道理，就像对着一扇关上的门大喊。

## 五步执行流程

1. **诊断归层**: 把问题翻译成四层框架，说清"卡在哪一层"
2. **稳状态 + 情绪确认**: 先连接再引导 — 跳进孩子的"洞"里陪他
3. **Plan B 协作**: 把控制换成合作式问题解决（Ross Greene）
4. **最小行动**: 30 秒锚点习惯 + 即时庆祝（BJ Fogg）
5. **一周微循环**: 一个指标、一周改一个点、复盘三问

## 适用与不适用

| ✅ 适用场景 | ❌ 不适用场景 |
|-------------|--------------|
| 孩子拖延、磨蹭、注意力散 | 用户要求诊断 ADHD、抑郁等医学问题 |
| 孩子哭闹、发脾气、怕上学、怕考试 | 孩子出现自伤、伤人、严重拒学 |
| 家长/老师不想再吼、催、威胁 | 用户只想要惩罚和控制话术 |
| 建立家庭规则、学习习惯、屏幕边界 | — |
