# 协作规则: Plan B 协作问题解决

> 参考 Ross Greene《The Explosive Child》+《Lost at School》+ 李浩英《高情商父母修习课》(原则五 行为引导 + 原则六 亲子沟通)

## 核心理念

> "Kids do well if they can." — Ross Greene

孩子不是"想做就能做好"。如果他们做不到，是因为:
1. **滞后技能 (lagging skills)**: 灵活思考、挫折耐受、情绪调节等能力还没发展到位
2. **未解决的问题 (unsolved problems)**: 具体的触发情境

惩罚和奖励都无法解决滞后技能。只有**协作**可以。

## 三种应对计划

| 计划 | 做什么 | 何时用 | 成人感受 |
|------|--------|--------|----------|
| **Plan A** | 成人单方面决定 | 安全紧急情况 | 控制感，但破坏关系 |
| **Plan B** | 成人与孩子协作解决 | 日常未解决问题 | 慢，但建立信任和技能 |
| **Plan C** | 暂时放下 | 低优先级问题 | 释然，给孩子空间 |

> 注意: Plan B 不是"给孩子想要的"，而是"一起找出双方都能接受的方案"。

## Plan B 三步详解

### Step 1: 共情 (Empathy)

**目标**: 让孩子先说，收集信息，不做评判。

**句式**:
- "我注意到 [客观观察，不含评判] ，怎么回事？"
- "我观察到 [具体行为] ，你那边发生了什么？"

**关键**:
- ❌ 不说: "我注意到你又没写作业，你怎么这么懒？" (评判)
- ✅ 说: "我注意到这周的作业有三天没交，怎么回事？" (客观+好奇)
- 如果孩子说"不知道"，继续温和提问: "是太难？太无聊？还是发生了别的事？"
- 这个阶段只倾听，不解决问题，不反驳

**完成信号**: 孩子说出了自己的视角，不再说"我不知道"或"随便"

### Step 2: 表达成人的担心 (Define Adult Concern)

**目标**: 说出你的担心，不指责孩子。

**句式**:
- "我的担心是..."
- "我担心的是..."

**关键**:
- ❌ 不说: "你这样下去以后怎么办？" (威胁)
- ✅ 说: "我的担心是，如果不交作业，老师无法知道你是否掌握了内容，你也可能会落下进度。"
- 只说事实，不说评判
- 保持简短

### Step 3: 邀请协作 (Invitation)

**目标**: 一起想出一个双方都能接受的方案。

**句式**:
- "我们能一起想一个办法，既能 [满足孩子的需求] ，又能 [解决成人的担心] 吗？"
- "我很好奇，你觉得有什么办法可以试试？"

**关键**:
- 让孩子先提出方案
- 方案必须: 现实可行 + 双方都同意
- 如果孩子提的方案不可行: "这是个想法，但我担心 [原因] 。还有别的办法吗？"
- 定下来后: "我们试三天，然后坐下来看看怎么样？"
- 方案失败 = 方案不好，不是孩子不好 → 回到 Step 1 重新来

## 常见错误

| 错误 | 为什么不行 | 正确做法 |
|------|-----------|----------|
| Step 1 就提出解决方案 | 孩子还没感到被理解 | 忍住，先听完 |
| 把 Plan B 当成 "说服孩子" | Plan B 是双向协作 | 双方都要让步 |
| Step 2 变成指责 | 孩子会关闭 | 只说"我担心"，不说"你错了" |
| 方案太模糊 | 无法执行和检查 | 具体到"什么时候、谁、做什么、多久" |
| 方案失败后放弃 | 协作是技能，需要练习 | 回到 Step 1 重新开始 |

## 各年龄段调整

- **3-6 岁**: 简化语言，用画画或玩偶表达；方案要非常具体 ("每次刷牙后可以选一个贴纸")
- **7-12 岁**: 可以书面记录方案；用"如果...那么..."句式
- **13-18 岁**: 给更多主导权；方案可以更复杂，但要有明确的核查时间

## 游戏契约

> "用'游戏契约'帮助家长摆脱无效说教，用善意沟通重建亲子信任。" — 李浩英

规则不必死板。把规则变成"游戏"，降低执行阻力:

### 契约要素

1. **命名**: 给规则起一个有趣的名字。不是"手机管理规则"，而是"手机充电大作战"
2. **时限**: 设定试验期。"我们先试 3 天，然后看看效果"
3. **角色**: 每个人都承担一个角色。"你是电量管理员，我是充电站站长"
4. **积分/徽章**: 不是惩罚违规，而是奖励遵守。"每次主动把手机放进充电站，得一颗星"
5. **升级**: 3 天后复盘，调整难度。"你觉得太容易还是太难？"

### 为什么有效

- 把"规则"变成"游戏" → 降低抵触
- 有时限 → 降低"永远都要这样"的压力
- 孩子参与设计规则 → 建立自主感
- 失败可以重来 → 体验"规则可以调整"而非"规则必须服从"

## 咬住底线，放大自由

> "坚守行为的规则: 咬住底线，放大自由的空间。" — 李浩英

这是 Plan B 的中国式表达，非常精炼。

### 三层自由模型

```
┌─────────────────────────────────┐
│  自由区: 孩子完全自主           │ ← "你想穿哪件衣服？"
│  (穿什么、玩什么、怎么安排)      │
├─────────────────────────────────┤
│  协商区: 亲子共同决定           │ ← Plan B 区域
│  (作业时间、屏幕时间、零花钱)    │    "我们一起想个办法"
├─────────────────────────────────┤
│  底线区: 不可协商               │ ← 安全、健康、法律
│  (不打人、不伤害自己、基本尊重)  │    "这个是底线，没有商量"
└─────────────────────────────────┘
```

**关键**: 
- 底线要少 (不超过 5 条)，要清楚，要一致
- 底线之外，能放就放
- "少用权力，多用规则" — 权力是"我说了算"，规则是"我们商量好的"

## 从"针锋相对"到"联手解决问题"

> 参考《高情商父母修习课》(原则五 行为引导)

李浩英提出的五步法，与 Greene 的 Plan B 高度一致:

1. 从情绪里走出来，辨别具体的问题是什么
2. 学会摄取不同的观点，从孩子的角度去看问题
3. 与孩子明确共同的目标，列出所有可能达成的路径
4. 列出每条路径的长处与短处，然后选择最适合的路径
5. 定期检测，如果无效，及时调整方案，直至产生最优结果
