# 沟通话术速查

> 参考 Adele Faber & Elaine Mazlish《How to Talk So Kids Will Listen & Listen So Kids Will Talk》+ BJ Fogg《Tiny Habits》

## 场景对话对照

以下 7 个场景覆盖 A2 中的 7 个触发信号。左边是家长本能的反应，右边是教练式的替代话术。

### 1. 拖延/磨蹭: "快去写作业！"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "快去写作业！说了多少遍了！" | "作业写完后，我们就可以 [孩子期待的事] 了。" |
| "你再磨蹭就别想玩游戏了！" | "先打开作业本看一眼今天的日期，我们就算开始了。" (30秒锚点) |
| "你怎么总是这么慢？" | "我注意到今天的作业有三项。你觉得先做哪一项最容易？" (给选择) |

### 2. 崩溃/哭闹: "他一写作业就哭"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "别哭了！有什么好哭的！" | "你看起来很沮丧。作业确实很难，对吗？" (情绪确认) |
| "你再哭就不理你了。" | "来，我们先喝口水，深呼吸三次。" (状态恢复) |
| "这么简单都不会？" | "这道题看起来让你很头疼。需要我陪你一起看看第一题吗？" |

### 3. 家长失控: "我不想总吼孩子"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| (吼叫) "你听到没有！" | "我需要一分钟想一想。" → 走出去深呼吸 → 回来低声说: "好了，我们重新来。" |
| "我已经受够了！" | "我现在很生气，所以我先去冷静一下。我们5分钟后聊。" (示范自我调节) |
| "你到底想怎么样？" | "我们能一起想一个办法吗？我注意到 [观察]，我担心 [原因]。你觉得怎么办？" (Plan B) |

### 4. 建立规则: "家里规则执行不下去"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "这是规矩，必须遵守！" | "这条规则是为了帮助你 [目的]，你觉得我们可以怎么一起做到？" |
| "不准玩手机！" | "手机可以在 [时间/地点] 使用。现在是作业时间，手机先放在充电站。" (给信息) |
| "你又犯规了！" | "我们约定好的规则是什么？下次可以怎么提醒自己？" (反思提问) |

### 5. 学校焦虑: "孩子怕上学/怕考试"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "有什么好怕的！你看别人都不怕。" | "上学/考试让你很紧张，对吗？能跟我说说最让你担心的是什么？" |
| "你必须去！" | "我理解你不想去。我们能不能先试第一步: 今天只去到学校门口，然后你再决定？" (逐步接近) |
| "考不好也没关系。" (敷衍) | "不管考得怎么样，我都爱你。我们来看看，哪一科你觉得需要帮忙？" |

### 6. 培养自驱力: "怎么让孩子自律？"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "你真聪明！" (空泛表扬) | "我注意到你试了三种方法才解开这道题，这个坚持真的很厉害！" (过程性表扬) |
| "你看 XX 多自觉！" (比较) | "你自己就完成了这一页，感觉怎么样？" (反思) |
| "快点做完！" | "耶！你打开作业本了！" → "下一步是什么？" (即时庆祝 → 下一步) |

### 7. 课堂管理: "课堂总是乱"

| ❌ 不要说 | ✅ 试着说 |
|-----------|----------|
| "安静！谁再说话就罚站！" | "我们一起来定三个课堂规则，每个人都签字。如果违反了，你们觉得怎么修复比较好？" (共同规则) |
| "你们班太差了。" | "刚才小组讨论的时候，我看到第三组的同学互相倾听，做得特别好。" (具体表扬) |
| "给我坐好！" | "大家看起来很累了。站起来伸个懒腰，做三次深呼吸，然后我们继续。" (脑休息) |

## 过程性表扬速查

| 夸特质 (❌) | 夸过程 (✅) |
|-------------|-------------|
| "你真聪明" | "你试了好几种方法，最后找到了答案" (策略) |
| "你真棒" | "刚才很难，但你坚持下来了" (坚持) |
| "你真乖" | "你看到同学难过就去安慰她，很温暖" (善意) |
| "你真厉害" | "你不知道怎么做的时候，主动来问我了" (求助) |
| "你做对了" | "你发现自己算错了，重新检查了一遍" (修复) |

## 反思提问速查

- "你刚才怎么做到的？" (帮助孩子看见自己的策略)
- "这次和上次比，哪里不一样了？" (帮助孩子看见进步)
- "下次卡住的时候，你会先做什么？" (帮助孩子建立预案)
- "从这个错误中学到了什么？" (把失败变成学习)
- "如果给今天的自己打一个分，10分满分，你打几分？差的那几分是什么？" (帮助孩子自我评估)

## 最小行动设计 (Fogg 行为模型)

> B = MAP (Behavior = Motivation + Ability + Prompt)

- **足够小**: 30 秒能完成。不是"背完这篇课文"，而是"打开课本读第一句"。
- **锚点 (Anchor)**: 绑定已有习惯。"每天刷牙后 → 写下今天要做的第一件事"。
- **即时庆祝 (Shine)**: 完成后立即庆祝 — 一个击掌，一句"耶！"，比任何延迟奖励都有效。
- **升级**: 当前最小行动稳定 3-5 天后，再升级到下一步。

### 最小行动示例

| 目标 | 太大 | 刚好 |
|------|------|------|
| 每天练琴 | 练 30 分钟 | 打开琴盖，弹一个音阶 |
| 每天阅读 | 读一章 | 翻到那一页，读第一句 |
| 整理房间 | 把房间整理干净 | 把地上的书放回书架 |
| 做作业 | 把作业做完 | 打开作业本，写下日期 |
